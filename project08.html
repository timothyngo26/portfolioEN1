Project 08: Astronaut Tools

This project focuses on tools designed for use in space. The challenge is to think about how equipment must work in environments with low gravity, limited space, and strict safety requirements.

Design considerations

  • Easy handling while wearing gloves or working in a constrained space
  • Lightweight design for limited payload and storage needs
  • Reliable function for repeated use in demanding conditions

The goal of the project is to explore practical design thinking for equipment that astronauts may need during missions, with an emphasis on usability, safety, and mission-ready functionality.

How the code works

The code runs the three connected motors at the same speed and in the same direction. Their movement turns the gear ratio to create the screw-in and unscrew motion. When the force sensor is pressed, the motors run; each new press switches their direction. They stop when the sensor is released.

Code used for the astronaut tool:

# Setup: motors on ports A, B, and C; force sensor on port D.
from hub import port
import runloop
import motor
import force_sensor

# Motor speed in degrees per second.
SPEED = 2000

async def main():
    # Start with the first press running in the positive direction.
    direction = 1

    # Keep checking whether the force sensor is held.
    while True:
        if force_sensor.pressed(port.D):
            # Switch direction for this press.
            direction = -direction

            # Run all three motors while the force sensor is held.
            motor.run(port.A, SPEED * direction)
            motor.run(port.B, SPEED * direction)
            motor.run(port.C, SPEED * direction)

            # Wait until the force sensor is released.
            while force_sensor.pressed(port.D):
                await runloop.sleep_ms(20)

            # Stop all three motors when the sensor is released.
            motor.stop(port.A)
            motor.stop(port.B)
            motor.stop(port.C)

        # Pause briefly before checking again.
        await runloop.sleep_ms(20)

runloop.run(main())
